# Basic HTML Website

## Overview

This project is a simple multi-page portfolio website built using **HTML only**, without CSS or JavaScript. The goal is to practice structuring a website with semantic HTML elements and creating navigation between multiple pages.

The project is based on the [Basic HTML Website project](https://roadmap.sh/projects/basic-html-website) from roadmap.sh.

## Pages

The website consists of four pages:

- **Homepage (`homepage.html`)** – Introduces the developer and presents projects, work experience, education, and teacher reviews.
- **Projects (`projects.html`)** – Lists the developer's projects.
- **Articles (`articles.html`)** – Displays articles about web development and HTML.
- **Contact (`contact.html`)** – Contains a contact form with fields for name, email, subject, and message.

## Technologies Used

- HTML5
- Semantic HTML elements
- HTML forms
- Internal navigation links
- SEO meta tags

## Features

- Multiple interconnected HTML pages.
- A consistent navigation bar on every page.
- Semantic page structure using elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- SEO metadata, including page titles, descriptions, and author information.
- A contact form with labeled input fields and basic browser-side validation.
- Organized content using headings, paragraphs, lists, and blockquotes.
- No CSS or JavaScript, keeping the focus on HTML structure.


## What I Learned

Through this project, I practiced:

- Creating multiple pages using HTML.
- Linking pages together with anchor elements.
- Structuring content with semantic HTML.
- Using headings and lists to organize information.
- Adding SEO meta tags to HTML documents.
- Creating accessible forms with labels and appropriate input types.
- Building a website structure that can be styled with CSS in future projects.
